# Tova Music Folder

Drop your own **licensed** soundtrack files here to enable in-game music.

Supported formats:
- `.ogg`
- `.mp3`
- `.wav`
- `.flac`

Behavior:
- Files are auto-discovered at startup.
- Tracks are queued as a long rotating playlist.
- Procedural ambient wind still plays underneath.

Notes:
- Tova does not ship third-party copyrighted songs in this folder.
- You can also set a custom directory with `TOVA_MUSIC_DIR=/absolute/path/to/music`.
